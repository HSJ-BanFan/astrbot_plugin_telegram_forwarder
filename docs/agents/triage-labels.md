# 🏷️ GitHub 5 大标准分类标签映射 (Triage Labels)

| 标签名称 (Label) | 颜色 (Hex) | 核心语义与流向 |
| :--- | :--- | :--- |
| **`ready-for-agent`** | `#0E8A16` | AI 智能体已就绪，直接领单开工（你个人开发 / 初审通过任务）。 |
| **`needs-triage`** | `#FBCA04` | 新提交的 Issue，等待架构师与分类器初审评估。 |
| **`needs-info`** | `#D93F0B` | 缺少必要复现步骤或日志，等待提交者补充。 |
| **`ready-for-human`** | `#5319E7` | 涉及高危权限、资金、对外发布或人类专属决策。 |
| **`wontfix`** | `#CCCCCC` | 重复提问、非预期缺陷或不予实现的反馈。 |
